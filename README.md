# Страница подписки с продлением

Сборка [remnawave/subscription-page](https://github.com/remnawave/subscription-page)
8.0.1 с изменениями (ноябрь 2026). Лицензия — AGPL-3.0, как у оригинала (`LICENSE`).

Образ Remnawave остаётся как есть (их сервер, выдача подписок VPN-клиентам),
заменён только собранный фронтенд: Dockerfile берёт исходники той же версии,
кладёт поверх `src/` и собирает.

## Что изменено

Файлы в `src/` повторяют пути `frontend/src` оригинала:

| Файл | |
|---|---|
| `widgets/main/subscription-info/subscription-info-expanded.widget.tsx` | Заменён. Блок «expanded»: статус словами («Подписка активна» и т. п.), когда кончается, трафик (только если ограничен), кнопка «Продлить». Включается в конфиге страницы: `uiConfig.subscriptionInfoBlockType: "expanded"` |
| `widgets/main/renewal/*` | Новые. Модалка продления: срок, число устройств и галочка «Сохранить карту для автопродления» (по умолчанию снята); ходит в API биллинга (`/api/renewal/options`, `/api/payments`) с shortUuid в заголовке `X-Subscription` |
| `pages/main/ui/components/main.page.component.tsx` | Заменён. Как в оригинале 8.0.1 плюс ссылка на исходники внизу |

## Сборка

```bash
docker build \
  --build-arg RENEWAL_API_URL=https://api.example.com \
  --build-arg SOURCE_URL=https://github.com/<владелец>/<репозиторий> \
  -t subscription-page:8.0.1 .
```

`RENEWAL_API_URL` — адрес API биллинга, `SOURCE_URL` — ссылка на исходники
этой сборки (показывается внизу страницы). Оба обязательны. Сборке нужен
доступ к GitHub, npm и Google Fonts и ~1,5 ГБ памяти. Если на сервере не
хватает, собрать на другой машине под `linux/amd64` и перенести:
`docker save <образ> | ssh <сервер> docker load`.

## Новая версия Remnawave

1. `PAGE_VERSION` в Dockerfile (или build arg).
2. Сравнить заменённые файлы с их новыми версиями в оригинале и перенести
   изменения (новые — не трогать). Собрать образ — заодно проверка типов.
3. Открыть страницу в браузере и проверить модалку продления.

## Лицензия

AGPL-3.0: изменённая версия работает в интернете, поэтому её исходники открыты
всем, кто ею пользуется, — этот репозиторий, ссылка на него внизу страницы.
